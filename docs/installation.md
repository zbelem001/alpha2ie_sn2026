# Installation

Ce dépôt contient uniquement la structure initiale. Il ne fournit pas encore d’application exécutable.

- Personne 1 : initialiser Next.js, React, TypeScript et Tailwind dans `frontend/`.
- Personne 2 : initialiser FastAPI et les dépendances Python dans `backend/`.
- Personne 3 : configurer PostgreSQL, Keycloak, les registres et Docker Compose dans `infrastructure/`.

Les versions, commandes de lancement, variables d’environnement et commandes de test seront documentées lors de l’initialisation des composants. Aucun secret réel ne doit être commité.
